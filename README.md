# Hbd# Hbd - Worldwide Social App

Hbd is a Facebook-style social media app built to connect the world.

### 🌍 Features (Facebook Style)
- 🔐 Secure Login / Signup (Email, Google)
- 📰 News Feed - Post Text, Images
- ❤️ Like, Comment, Share System
- 👤 User Profile & Bio
- 👥 Add Friend / Follow System
- 💬 Real-time Chat (Coming Soon)
- 🔔 Notifications

### 🛠️ Built With
- Sketchware Pro v6.4.0
- Firebase Auth, Firestore, Storage
- Java

### 🚀 Goal
To run worldwide like Facebook. Connect, Share, Chat globally.
